# Мои финансы — учёт доходов и расходов

Личный сервис для учёта доходов и расходов. Работает в браузере, без регистрации и сервера:
все данные хранятся в `localStorage` на твоём устройстве.

## Возможности

- **Операции и баланс** — добавление, редактирование и удаление доходов и расходов; общий баланс,
  доходы, расходы и итог за выбранный месяц.
- **Категории и фильтры** — свои категории (название, цвет), фильтр по типу, категории и поиск по
  комментарию; переключение месяцев или режим «Всё время».
- **Статистика** — круговая диаграмма по категориям и динамика доходов/расходов за 6 месяцев.
- **Бюджеты** — месячный лимит на категорию расходов с индикатором (жёлтый от 80%, красный при превышении).
- **Данные** — резервная копия и восстановление (JSON), экспорт в CSV для Excel, сброс.

## Запуск

```bash
cd finance-tracker
npm install
npm run dev       # режим разработки, http://localhost:5173
npm run build     # проверка типов и сборка в dist/
npm run preview   # просмотр собранной версии
```

Папку `dist/` после сборки можно выложить на любой статический хостинг (GitHub Pages, Netlify,
Vercel и т.п.).

## Важно про данные

Данные живут только в браузере, где ты ими пользуешься: на другом устройстве или в другом браузере
их не будет, а очистка данных сайта их удалит. Регулярно скачивай резервную копию в «Настройки → Данные».

## Структура

```
src/
  types.ts          модели данных
  store.ts          состояние, редьюсер, загрузка/сохранение, проверка импорта
  utils.ts          даты, форматирование сумм, вспомогательные функции
  App.tsx           каркас: шапка, итоги, вкладки
  components/       PeriodPicker, Summary, TransactionList, TransactionForm, Stats, Budgets, Settings
```
